Attack Taxonomy

The 3 Primary Adversarial Graph Topologies

🚨 DRAIN_STAR CRITICAL / BLOCK

A malicious sink contract receives rapid, concurrent fund transfers from multiple victims (agents, treasuries) in a radial fan-in pattern, followed immediately by bridge sweeps.

Topological Signature
High In-Degree (≥5) • Asymmetric Fan-In • High Outflow Dissipation
FIREWALL ACTION: Reject RPC payload (-32003) & blacklist destination.
⚡ MIXING_CHAIN WARNING / ESCALATE

Sequential multi-hop fund splitting through peeling chains, relay proxies, or unverified cross-chain bridges designed to obfuscate origin funds from linear heuristic filters.

Topological Signature
Hop Path Length ≥ 4 • Linear Peeling • Entropy > 0.85
FIREWALL ACTION: Divert to human multisig confirmation before signing.
🕸️ COORD_CLUSTER ANOMALY / ESCALATE

Sybil clusters executing synchronized front-running, sandwich attacks, or liquidity drain coordination against agent rebalancing trades on decentralized exchanges.

Topological Signature
Dense k-clique subgraph • Microsecond synchronized nonce sequences
FIREWALL ACTION: Enforce private mempool relay or delay order inclusion.
