Move Objects Paradigm (AIP-XX) RESOURCE SAFETY

Unlike EVM mapping structures vulnerable to reentrancy, Aptos Move Objects represent agent profiles as unique, non-fungible on-chain entities. Each agent profile object stores cryptographic identity, capabilities, and reputation state directly tied to the agent's controller address.

• Non-fungible linear resource guarantees zero double-registration.
• Dynamic capability transfers permit automated custodian delegation.
• Interoperable with Aptos Object Transfer and Keyless accounts.
Deterministic Slashing & Quarantine ZERO TOLERANCE

When Imina-Na V2 detects an agent attempting interaction with a confirmed DRAIN_STAR contract, an oracle slashing proof is dispatched to the contract. The agent's score is slashed by 300 points in one block, immediately demoting them to Bronze and revoking signing rights.

• -300 point penalty for confirmed drain-star ingress interaction.
• Bonded stake escrow liquidated to decentralized insurance pool.
• Quarantine requires 14-day human governor challenge period.

struct AgentProfile has key, store {
    did: String,          // "did:sigui:aptos:0x8332..."
    tier: u8,             // 0=Bronze, 1=Silver, 2=Gold, 3=Platinum
    score: u64,           // 0 to 1000 saturating
    tx_count: u64,        // Total audited actions
    blocked_count: u64,   // Intercepted malicious interactions
    slashed_stake: u64,   // Slashed Octas deposited to insurance
    is_active: bool,      // Active status (false if quarantined)
}
