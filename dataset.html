📋 Parquet Record Schema Specification APACHE ARROW SCHEMA
FIELD TYPE DESCRIPTION EXAMPLE
graph_id string Unique deterministic hash of the audited neighborhood "0x3806_drain_sample_42"
nodes_count int32 Total unique wallet and contract vertices in the 2-hop graph 8
edges_count int32 Directed transaction transfers and internal call traces 7
topology_label string Categorical ground-truth classification "DRAIN_STAR"
visual_matrix float32[64][64] Normalized 2D adjacency matrix for vision transformers [0.0, 0.94, ..., 0.0]
risk_ground_truth float32 Continuous exploit risk score (0.00 benign to 1.00 critical) 0.984
⚡ Quickstart: Load Dataset in Python HUGGING FACE DATASETS
load_dataset.py
APACHE ARROW COMPATIBLE
# 1. Install Hugging Face datasets library:
$ pip install datasets pyarrow torch

# 2. Stream or download the 1M Graph split directly:
from datasets import load_dataset

dataset = load_dataset("Ibonon/sigui-depin-1m")
sample = dataset["train"][0]

print(f"Graph: {sample['graph_id']} | Label: {sample['topology_label']} | Risk: {sample['risk_ground_truth']}")
# Output: Graph: 0x3806_drain_sample_42 | Label: DRAIN_STAR | Risk: 0.984
