📦 ElizaOS v2 Plugin NPM PACKAGE

Adds the SIGUI_THREAT_INTEL provider to inform your character's LLM of malicious addresses and the AUDIT_TRANSACTION action to automatically block drain transfers before signing. 

# 1. Install via NPM:
$ npm install sigui-elizaos-plugin

# 2. Register in character.json:
{
  "name": "TraderAgent",
  "plugins": ["sigui-elizaos-plugin"],
  "settings": {
    "secrets": { "SIGUI_RPC_URL": "https://rpc.sigui.io/v1/ethereum" }
  }
}
🦜 LangChain / LangGraph Callback PYTHON PIP

Intercepts tool execution in LangGraph and LangChain agents. If an agent attempts to invoke a Web3 transfer tool with a malicious destination, the callback raises a security exception. 

# Attach SiguiSecurityCallback to your agent:
from sigui.integrations.langchain import SiguiSecurityCallback

sigui_guard = SiguiSecurityCallback(fail_closed=True)

agent_executor = create_react_agent(
    model, tools,
    callbacks=[sigui_guard]
)

🐍 Native Python SDK PYPI CLIENT

Lightweight asynchronous client for Python trading bots, algorithmic arbitrage scripts, and autonomous Web3 backends across EVM, Move, and Solana. 

# Install from PyPI:
$ pip install sigui-sdk

from sigui import SiguiClient

client = SiguiClient()
verdict = await client.audit_address("0x3806...", chain="aptos")
if verdict.decision == "BLOCK":
    raise SecurityThreat(verdict.reason)
