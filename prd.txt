## 4. 🎯 Problem Statement — 7 dimensions

**Dimension 1 — Paiements anormaux :** Transactions USDC aberrantes d'agents compromis. Coût SIEM traditionnel : $0.30/tx — structurellement impossible sur nano-paiements.

**Dimension 2 — Transaction splitting :** Fragmentation de $45 en 90 × $0.50. Invisible transaction par transaction. Détectable uniquement sur fenêtres cumulées.

**Dimension 3 — Services frauduleux :** Faux services API qui empoisonnent les données des agents. Le dommage n'est pas le USDC volé — c'est l'intégrité des décisions corrompue.

**Dimension 4 — Smart contracts malveillants :** Fonctions drain cachées dans le bytecode EVM. Un seul appel vide le wallet.

**Dimension 5 — Topologie visuelle des attaques :** Les patterns d'attaque coordonnés (DRAIN_STAR, MIXING_CHAIN, COORDINATED_CLUSTER) créent des signatures visuelles dans le graphe de transactions — invisibles au texte, immédiatement reconnaissables pour un modèle de vision. Un modèle pré-entraîné générique atteint 88% de précision. Un modèle fine-tuné sur des données blockchain atteint 96%.

**Dimension 6 — La boucle ouverte :** La sécurité agentique actuelle est fournie par des systèmes humains extérieurs à la boucle. Latence incompatible, dépendance structurelle.

**Dimension 7 — Le silo blockchain :** Les agents sur Solana ne peuvent pas interroger un oracle sur Ethereum sans bridges complexes. L'économie agentique est multi-chaîne par nature — la sécurité doit l'être aussi.

## 8. ⚙️ Module 1 — Hogon (Agent Core)

**Mythologie :** Le Hogon est le grand prêtre Dogon, gardien du feu sacré et de la mémoire collective.

**Rôle :** Boucle autonome 100ms. Orchestre les 5 couches. Consulte les paramètres du DAO Hogonat. Décide de son mode selon la trésorerie multi-chain consolidée.

**Stack :** asyncio · dataclasses · enum · Loguru

```python
class OperatingMode(str, Enum):
    NORMAL    = "NORMAL"     # Balance > $1.00 · toutes couches actives
    DEGRADED  = "DEGRADED"   # Balance $0.20–$1.00 · Imina Na réduite
    EMERGENCY = "EMERGENCY"  # Balance < $0.20 · règles seules

class HogonCore:
    """Le gardien du feu sacré de l'économie agentique."""

    async def run(self):
        while True:
            # 1. Charger les paramètres DAO actuels
            self.risk_weights = await hogonat.get_current_weights()
            self.thresholds   = await hogonat.get_thresholds()

            # 2. Sync trésorerie toutes les 30s
            if self.cycle % 300 == 0:
                await tresor.sync_all_chains()

            # 3. Décider le mode opérationnel
            self.mode = tresor.operating_mode

            # 4. Log
            if self.cycle % 100 == 0:
                logger.info(
                    f"[HOGON #{self.cycle}] mode={self.mode} "
                    f"balance=${tresor.total_balance:.4f} "
                    f"chains={tresor.active_chains}"
                )

            await asyncio.sleep(0.1)
```

## 10. ⚙️ Module 3 — Kanaga (Risk Engine v3)

**Mythologie :** Le masque Kanaga représente le mouvement de la création, le brassage des forces cosmiques. Il calcule l'équilibre.

**Rôle :** Score R final en agrégeant les 5 couches sur AMD MI300X via PyTorch ROCm.

**Stack :** PyTorch ROCm · AMD MI300X · numpy (fallback CPU) · Pydantic v2

**Migration numpy → PyTorch ROCm :**
```python
import torch

DEVICE = torch.device("cuda")  # ROCm == "cuda" sur AMD

class KanagaEngine:

    def __init__(self, weights: list[float] = None):
        # Poids initialisés depuis le DAO Hogonat
        w = weights or [0.40, 0.30, 0.30]
        self.weights = torch.tensor(w, device=DEVICE, dtype=torch.float32)

    async def compute(self, action: ActionInput,
                       history: dict,
                       deltas: dict) -> RiskOutput:

        A = self._score_action(action, history)
        C = self._score_context(action, history)
        H = self._score_history(history)

        scores = torch.tensor([A, C, H], device=DEVICE)
        R_base = torch.clamp(torch.dot(self.weights, scores), 0.0, 1.0)

        # Deltas des couches externes
        flow_delta     = deltas.get("flow", 0.0)
        service_delta  = deltas.get("service", 0.0)
        contract_delta = deltas.get("contract", 0.0)
        vision_delta   = deltas.get("vision", 0.0)

        R_final = float(torch.clamp(
            R_base + flow_delta + service_delta + contract_delta + vision_delta,
            0.0, 1.0
        ))

        return RiskOutput(
            risk_score=round(R_final, 4),
            components={"action": A, "context": C, "history": H},
            deltas=deltas,
            rules_triggered=self._triggered_rules,
            device="AMD MI300X"
        )

    async def compute_batch(self, actions_data: list[dict]) -> list[float]:
        """Évaluation de N agents en parallèle sur GPU — différenciateur AMD."""
        n = len(actions_data)
        matrix = torch.zeros((n, 3), device=DEVICE)
        for i, d in enumerate(actions_data):
            matrix[i] = torch.tensor([d["A"], d["C"], d["H"]])
        results = torch.clamp(matrix @ self.weights, 0.0, 1.0)
        return results.cpu().tolist()
```

## 12. ⚙️ Module 5 — Trésor du Sigui (Treasury Multi-Chain)

**Stack :** Circle Developer-Controlled Wallets × 6 · httpx async · aiosqlite · asyncio.Lock

**Trésorerie consolidée :**
```python
@property
def total_balance(self) -> float:
    """Balance USDC consolidée sur toutes les chaînes."""
    return sum(self._balances.values())

async def record_revenue(self, amount: float, chain: str, agent_id: str):
    """Enregistre un revenu selon la chaîne source."""
    async with self._lock:
        self._balances[chain] = self._balances.get(chain, 0) + amount
        self._total_earned    += amount
        await self._log("revenue", amount, chain, agent_id)

async def pay_for_vision(self) -> bool:
    """Sigui paie l'inférence Imina Na depuis sa trésorerie."""
    cost = 0.0002
    async with self._lock:
        if self.total_balance < cost:
            return False
        self._balances["arc"] = self._balances.get("arc", 0) - cost
        self._total_spent += cost
        await self._log("expense", cost, "amd_inference", "imina_na")
        return True
```

```tsx
"use client"
import ReactFlow, {
  Node, Edge, Background, Controls,
  useNodesState, useEdgesState
} from "reactflow"
import "reactflow/dist/style.css"
import { useEffect } from "react"

interface Props {
  decisions: Decision[]
}

export function DivinationBoard({ decisions }: Props) {
  const [nodes, setNodes, onNodesChange] = useNodesState([])
  const [edges, setEdges, onEdgesChange] = useEdgesState([])

  useEffect(() => {
    // Reconstruire le graphe depuis les dernières décisions
    const newNodes: Node[] = []
    const newEdges: Edge[] = []
    const seen = new Set<string>()

    decisions.slice(0, 15).forEach((d, i) => {
      const src = d.agent_id.slice(0, 8)
      const dst = d.destination?.slice(0, 8) ?? "0xUnknown"

      if (!seen.has(src)) {
        seen.add(src)
        newNodes.push({
          id: src,
          position: { x: (i % 5) * 160, y: Math.floor(i / 5) * 120 },
          data: { label: src },
          style: {
            background: d.decision === "BLOCK" ? "#E24B4A22"
                      : d.decision === "ESCALATE" ? "#8b5cf622"
                      : "#1D9E7522",

              d.decision === "BLOCK" ? "#E24B4A"
            : d.decision === "ESCALATE" ? "#8b5cf6"
            : "#1D9E75"}`,
            color: "white",
            borderRadius: "8px",
            fontSize: "10px",
            fontFamily: "Space Mono",
          }
        })
      }

      newEdges.push({
        id: `${src}-${dst}-${i}`,
        source: src,
        target: dst,
        animated: d.decision === "BLOCK",
        style: {
          stroke: d.decision === "BLOCK" ? "#E24B4A"

    setNodes(newNodes)
```

```typescript
  total: number
  allow: number
  block: number
  escalate: number
  protected: number
  profit: number
}

export function useSiguiFeed() {
  const [stats, setStats]       = useState<SiguiStats>(
    { total: 0, allow: 0, block: 0, escalate: 0, protected: 0, profit: 0 }
  )
  const [mode, setMode]         = useState("NORMAL")
  const [decisions, setDecisions] = useState<Decision[]>([])
  const ws = useRef<WebSocket | null>(null)

  useEffect(() => {
    // WebSocket vers FastAPI backend
    ws.current = new WebSocket("ws://localhost:8000/ws/feed")

    ws.current.onmessage = (event) => {
      const data = JSON.parse(event.data)

      if (data.type === "decision") {
        setDecisions(prev => [data.payload, ...prev].slice(0, 50))
        setStats(prev => ({
          ...prev,
          total:    prev.total + 1,
          allow:    data.payload.decision === "ALLOW"    ? prev.allow + 1    : prev.allow,
          block:    data.payload.decision === "BLOCK"    ? prev.block + 1    : prev.block,
          escalate: data.payload.decision === "ESCALATE" ? prev.escalate + 1 : prev.escalate,
          protected: data.payload.decision === "BLOCK"
            ? prev.protected + (data.payload.amount_usdc ?? 0)
            : prev.protected,
          profit: prev.profit + (data.payload.evaluation_price_usdc ?? 0.001)
        }))
      }

      if (data.type === "mode_change") {
        setMode(data.payload.mode)
      }
    }

    // Polling fallback si WebSocket non disponible
    const interval = setInterval(async () => {
      if (ws.current?.readyState !== WebSocket.OPEN) {
        const [statsRes, decisionsRes] = await Promise.all([
          fetch("http://localhost:8000/treasury").then(r => r.json()),
          fetch("http://localhost:8000/stats").then(r => r.json()),
        ])
        setMode(statsRes.mode ?? "NORMAL")
        setDecisions(decisionsRes.recent ?? [])
      }
    }, 2000)

    return () => {
      ws.current?.close()
      clearInterval(interval)
    }
  }, [])

  return { stats, mode, decisions }
}
```

**Endpoint WebSocket dans FastAPI (`main.py`) :**
```python
from fastapi import WebSocket, WebSocketDisconnect
from typing import List

class ConnectionManager:
    def __init__(self):
        self.active: List[WebSocket] = []

    async def connect(self, ws: WebSocket):
        await ws.accept()
        self.active.append(ws)

    async def disconnect(self, ws: WebSocket):
        self.active.remove(ws)

    async def broadcast(self, message: dict):
        import json
        for ws in self.active:
            try:
                await ws.send_text(json.dumps(message))
            except Exception:
                pass

manager = ConnectionManager()

@app.websocket("/ws/feed")
async def websocket_feed(websocket: WebSocket):
    await manager.connect(websocket)
    try:
        while True:
            await websocket.receive_text()  # keep-alive
    except WebSocketDisconnect:
        await manager.disconnect(websocket)
```

**Hook `hooks/use-treasury.ts` :**
```typescript
"use client"
import { useEffect, useState } from "react"

interface TreasuryState {
  arc_balance:   number
  eth_balance:   number
  sol_balance:   number
  net_profit:    number
  total_earned:  number
  total_spent:   number
  mode:          string
}

export function useTreasury() {
  const [treasury, setTreasury] = useState<TreasuryState>({
    arc_balance: 0, eth_balance: 0, sol_balance: 0,
    net_profit: 0,  total_earned: 0, total_spent: 0,
    mode: "NORMAL"
  })

  useEffect(() => {
    async function poll() {
      try {
        const r = await fetch("http://localhost:8000/treasury")
        const d = await r.json()
        setTreasury({
          arc_balance:  d.chain_balances?.arc      ?? 0,
          eth_balance:  d.chain_balances?.ethereum ?? 0,
          sol_balance:  d.chain_balances?.solana   ?? 0,
          net_profit:   d.net_profit    ?? 0,
          total_earned: d.total_earned  ?? 0,
          total_spent:  d.total_spent   ?? 0,
          mode:         d.mode          ?? "NORMAL",
        })
      } catch { /* silently fail */ }
    }

    poll()
    const id = setInterval(poll, 3000)
    return () => clearInterval(id)
  }, [])

  return { treasury }
}
```

## 24. 💰 Modèle Économique — La Taxe Cosmique

Un modèle économique en 3 couches qui capture la valeur réelle fournie par le protocole, tout en restant abordable pour les agents.

**Couche 1 — Percentage-based (Pay-As-You-Go) :**

```python
# modules/pricing.py

BASIS_POINTS = 5      # 0.05%
MINIMUM_FEE  = 0.01   # $0.01
MAXIMUM_FEE  = 100.00 # $100

def compute_fee(amount_usdc: float,
                tier: str = "payg") -> float:
    """
    Pay-as-you-go : proportionnel plafonné.
    Abonnement : inclus dans le quota mensuel.
    """
    if tier in ("novice", "hogon", "sigui"):
        return 0.0  # inclus dans l'abonnement

    fee = amount_usdc * (BASIS_POINTS / 10_000)
    return round(min(max(fee, MINIMUM_FEE), MAXIMUM_FEE), 6)
```

**Pourquoi 5 basis points (0.05%) ?**
Sigui est ultra-compétitif :
- Stripe (paiements) : 290 bps (2.9%)
- Uniswap (DEX) : 30 bps (0.3%)
- **Sigui (sécurité agentique) : 5 bps (0.05%)**
Sigui est 6× moins cher qu'Uniswap pour une protection directe.

**Couche 2 — Abonnements SaaS (Agents haute fréquence) :**

| Tier | Prix/mois | Inclus |
|---|---|---|
| **NOVICE** | $29 | 50 000 évals, Couches 1-4, 1 chaîne |
| **HOGON** | $199 | 500 000 évals, Imina Na, 3 chaînes, Priorité |
| **SIGUI** | $999 | Illimité, Fine-tuning, Toutes chaînes, SLA |

**Couche 3 — Staking rewards (Hogonat DAO) :**
- **70%** → Trésor Sigui (opérations, AMD cloud)
- **20%** → Pool Hogonat (redistribué aux stakers, ~24% APY estimé)
- **10%** → Fonds de réserve (couverture des erreurs)

**Margin Story AMD :**

| Réseau | Fee moyen | Viable $0.001 ? |
|---|---|---|
| Ethereum | $0.50–$5 | ❌ Fee = 500× le prix |
| Polygon | $0.01–$0.05 | ❌ Fee = 10× le prix |
| **Arc L1** | **~$0.000003** | **✅ Fee = 0.3% du prix** |

## 31. 📝 Circle Product Feedback

**Produits :** Arc Testnet · Circle DCW × 6 · USDC · x402 · Circle Developer Console

**Nouveauté v2.0 :** Sigui introduit un pricing proportionnel via x402 — `max($0.001, amount × 0.0005)`. Cela implique que le header HTTP 402 doit retourner un montant calculé dynamiquement selon la valeur de la transaction à sécuriser. Les Developer-Controlled Wallets de Circle permettent à Sigui (agent autonome) de recevoir des paiements de montants variables sans intervention humaine — c'est exactement le cas d'usage DCW.

**Feedback produit :**
1. Un endpoint `POST /v1/wallets/{id}/batch-transfer` permettrait de gérer les paiements de staking vers plusieurs stakers Hogonat en une seule opération.

3. Des exemples de code pour le pattern "agent reçoit paiements variables selon formule" seraient très utiles dans la documentation DCW.
