Developer Manual & Specifications

Developer Quickstart & API

Get started with Sigui in under 60 seconds. Choose between the zero-installation hosted RPC endpoint or run the lightweight local proxy for your agent infrastructure.

Hosted Proxy URL https://rpc.sigui.io/v1/{chain}
Local Default Port http://127.0.0.1:8545
Interception Overhead < 30 ms
Fail-Safe Policy Fail-Closed Default
Option 1: Hosted Zero-Install (Cloud) NO CODE

Replace your current node URL in your agent's environment variables. All transactions are intercepted and audited seamlessly before reaching the blockchain. 

# .env file of your agent:
ETHEREUM_RPC="https://rpc.sigui.io/v1/ethereum"
ARBITRUM_RPC="https://rpc.sigui.io/v1/arbitrum"
BASE_RPC="https://rpc.sigui.io/v1/base"
APTOS_FULLNODE="https://rpc.sigui.io/v1/aptos"
SOLANA_RPC="https://rpc.sigui.io/v1/solana"
Option 2: Local Docker / CLI Proxy DEV MODE

Run the proxy locally alongside your bot or trading script. Requires Python 3.10+ and intercepts all standard JSON-RPC requests. 

# Clone and start proxy:
$ git clone https://github.com/ibonon/Sigui.git
$ cd Sigui
$ python -m modules.sigui_guard --port 8545 --network ethereum

# Connect your Python Web3 agent:
w3 = Web3(Web3.HTTPProvider("http://127.0.0.1:8545"))
📡 Core HTTP & JSON-RPC Endpoints REST API SPECIFICATION
ENDPOINT METHOD DESCRIPTION RESPONSE
/v1/{chain} POST Intercepts eth_sendRawTransaction, sendTransaction JSON-RPC result or Error -32003 (BLOCK)
/v1/aptos/transactions POST Intercepts Aptos REST transaction payload HTTP 200 (Forwarded) or HTTP 403 (BLOCKED)
/api/evaluate POST Direct audit of a contract address or transaction graph { decision: "ALLOW"|"BLOCK", risk_score, pattern }
/health GET Proxy and vision model health check { status: "healthy", version: "3.2.0" }
