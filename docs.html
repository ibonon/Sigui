Quickstart Guide

Get Protected in 60 Seconds: Choose Your Deployment

Option A: Hosted Zero-Install (Cloud) ZERO CODE

Replace your current blockchain node endpoint in your agent's configuration. All raw transactions are intercepted and audited by the MI300X cluster before consensus broadcast.

.env (Agent Configuration)
# Update your agent's RPC endpoint:
ETHEREUM_RPC="https://rpc.sigui.io/v1/ethereum"
ARBITRUM_RPC="https://rpc.sigui.io/v1/arbitrum"
BASE_RPC="https://rpc.sigui.io/v1/base"
APTOS_RPC="https://rpc.sigui.io/v1/aptos"
SOLANA_RPC="https://rpc.sigui.io/v1/solana"
Option B: Self-Hosted Daemon (Local) SOVEREIGN

Run the lightweight proxy daemon locally inside your bot's virtual environment or Docker network. Intercepts standard JSON-RPC on localhost port 8545.

terminal / bash
# 1. Run local Sigui Guard daemon:
$ git clone https://github.com/ibonon/Sigui.git
$ cd Sigui && python launch_all.py --port 8545

# 2. Point your Web3 agent to localhost:
w3 = Web3(Web3.HTTPProvider("http://127.0.0.1:8545"))
📡 Core HTTP & JSON-RPC Endpoints REST & RPC SPECIFICATION
ENDPOINT METHOD PURPOSE EXPECTED RESPONSE
/v1/{chain} POST Transparent reverse proxy for eth_sendRawTransaction Node consensus response OR Error -32003 (BLOCK)
/v1/aptos/transactions POST Intercepts Aptos REST transaction submission payloads HTTP 200 (Forwarded) OR HTTP 403 (BLOCKED)
/api/evaluate POST Direct programmatic audit of an address or adjacency graph { decision: "ALLOW"|"BLOCK", risk_score, pattern }
/api/threat-intel GET Fetches dynamic blacklist of learned threat addresses { total_learned, patterns: [...] }
/health GET Cluster liveness, ROCm GPU memory, and latency health check { status: "healthy", version: "3.2.0" }

Standard Agent Rejection Handling EIP-1474

By adhering to EIP-1474 custom server error code -32003, popular agent libraries like Ethers.js, Web3.py, and Viem automatically catch the exception: 

try:
    tx_hash = w3.eth.send_raw_transaction(signed_tx)
except ContractLogicError as e:
    if e.code == -32003:
        logger.error(f"🚨 Treasury protected: {e.message}")
