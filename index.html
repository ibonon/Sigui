What is Sigui Protocol?

When an AI agent (ElizaOS, AutoGPT, trading bot) initiates a transaction, Sigui intercepts the payload at wire-speed, analyzes the transaction topology with computer vision, verifies the safety invariants in ZK, and aborts before the treasury is drained.

Core Capabilities

The Three Architectural Pillars

Explore Full Architecture →
01. VISION RECOGNITION QWEN2-VL + MI300X

Converts transaction call graphs into visual adjacency matrices. Bypasses smart contract code obfuscation by inspecting flow topologies directly.

02. CRYPTOGRAPHIC PROOF GROTH16 ZK

Generates succinct 64-byte non-drain proofs over the BN128 prime field. Proves transaction benignity on-chain without revealing sensitive trading strategies.

03. TRANSPORT FIREWALL RPC PROXY

Universal drop-in RPC proxy for EVM, Aptos, Starknet, and Solana. Requires 0 code changes in agent logic — developers update only their RPC endpoint URL.
